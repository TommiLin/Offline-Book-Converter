# Сборка и обновления

Официальный репозиторий: https://github.com/TommiLin/Offline-Book-Converter.
Адрес закреплён в app/updater.py; настройки, переменные окружения и параметры сборки его не меняют.

## Первая публикация

1. Загрузи содержимое source ZIP в корень указанного репозитория, включая скрытую папку .github.
2. Включи GitHub Actions, если GitHub предложит это сделать.
3. Отправь тег v1.3.6 после загрузки файлов: `git tag v1.3.6`, затем `git push origin v1.3.6`.
4. Дождись успешного завершения **Build and release Windows app** в Actions.

Сценарий проверит номер версии, запустит тесты, соберёт установщик, portable и source ZIP и SHA256SUMS.txt. Затем создаст черновик релиза, загрузит все файлы и опубликует релиз. Публикация разрешена только в TommiLin/Offline-Book-Converter. Используется встроенный GITHUB_TOKEN; дополнительные секреты не нужны.

Ручной запуск Actions создаёт скачиваемый артефакт Windows-build без публикации релиза. Если публикация прервалась, удали незавершённый черновик и повтори запуск. Опубликованные версии не перезаписывай.

## Следующие версии

Измени version в app/update_config.json (сейчас {"version":"1.3.6"}), обнови CHANGELOG.md, отправь изменения и соответствующий тег vMAJOR.MINOR.PATCH. В приложении останется только **Check for updates**. Проверяются стабильные публичные релизы; установщик скачивается после подтверждения и проверяется по SHA-256. Затем пользователь подтверждает запуск установки.

## Локальная сборка Windows

Требуются Python 3 с Tkinter и .NET Framework 4.x. Выполни:

```powershell
python -m unittest discover -s tests -v
python scripts/build.py
```

Готовые файлы находятся в dist. Python и Calibre устанавливаются отдельно для работы программы. При установленном Calibre тесты движка запускаются командой `calibre-debug -e tests/test_chapterless.py`.

Установщик поддерживает `/extract-only PATH` для проверки распаковки без регистрации и ярлыков; `/check-files PATH` проверяет занятые файлы (0 — доступны, 32 — заняты, 1 — другая ошибка); `/update-dir PATH` выбирает существующую папку установки.

В исходном архиве нет книг, личных настроек, временных папок и готовых EXE. В релизе нужны все четыре файла из dist, включая SHA256SUMS.txt. После публикации проверь **Check for updates** из предыдущей версии с тем же закреплённым репозиторием.
